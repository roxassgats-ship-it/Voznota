# 09 · Catálogo total de facultades e ingenierías

Pediste abarcar TODOS los tipos de ingeniería y materia: historia, telecomunicaciones,
tecnológico, técnico, magíster, todo. Este es el registro civil completo. Cada
**facultad** agrupa ingenierías; cada **ingeniería** tiene subcampos; cada subcampo
madura igual que siempre: skills → ingeniero → profesor → director → **empresa propia**
(ver archivo 10).

Regla de apertura: una ingeniería NO se abre por capricho, se abre cuando hay
**demanda real** (tareas tuyas que caen en ese campo 3+ veces). Este catálogo es el
mapa de todo lo abrible; se abre a demanda para no fundir el presupuesto.

escrito en los límites de cada agente.

## Cómo se abre una facultad nueva (procedimiento)

1. **Demanda:** 3+ tareas reales tuyas caen en un campo sin ingeniero.
2. **Acta de apertura:** el ingeniero-producto lo registra y propone la apertura.
3. **Kit inicial:** se copian las plantillas → 1 examen de Grado 1 del campo,
   1 lección de nivelación, 1 skill semilla. (Medio día de trabajo de un profesor.)
4. **Alumno fundador:** se asigna el modelo según presupuesto (tabla del archivo 10).
5. **Registro:** fila nueva en este catálogo + fila en el tablero de métricas.

El catálogo crece a demanda, pero el TECHO es este archivo: si un campo no está
acá, primero se agrega acá (con tu firma), después se abre. Así el colegio abarca
"todo" sin dispersarse en materias que nadie usa.
